# Getting Started

This section takes you from a bare flight controller to a first connection,
ready to set up a helicopter.

1. [Download](downloads.md) the Configurator -- or skip the install and use
   the web version at [cfg.rotorflight.org](https://cfg.rotorflight.org).
2. [Flash the firmware](flashing-the-firmware.md) onto your flight controller.
3. Make a [first connection](first-connection.md) and check the board is
   alive and the right way up.
4. Read [Arming & Safety](arming.md) before you ever power a helicopter with
   blades fitted.
5. Work through the [Setup Guides](../setup/index.md): receiver, servos,
   swashplate, ESC, governor and RPM filters.
6. Once it flies, take a [backup](backup-and-restore.md) before you start
   tuning.

Updating an existing helicopter to a new release? Read the
[Upgrade Notes](upgrade-notes.md) first -- some releases need parts of the
configuration redone.

!!! tip "Follow along with a real build"
    The [Example Build](example-build.md) walks through a complete setup of
    a small electric helicopter from start to finish, linking to the
    detailed pages as it goes.

If you get stuck, the [Rotorflight Discord](https://discord.gg/FyfMF4RwSA)
is the fastest place to get help.
